Final pool of implemented tasks from BenchTasksCollv3.

This directory (`tasks/finalpool/`) contains all tasks whose development status on the Notion
Task Tracker was verified as `implemented`. Each task folder preserves the structure required
by `tasks/examples`:

- `docs/task.md` — non-empty, all English
- `docs/agent_system_prompt.md` — non-empty, all English
- `docs/user_system_prompt.md` — optional; all English when present
- `evaluation/main.py` — evaluation entry script
- `preprocess/main.py` — optional preprocessing entry script
- `groundtruth_workspace/` — optional ground-truth workspace
- `initial_workspace/` — optional initial workspace
